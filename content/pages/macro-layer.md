## 宏观层的唯一职责

宏观环境层为所有产品提供同一份环境描述和共同风险边界。它负责回答：

- 当前环境由哪些可核验事实构成；
- 环境正在改善、恶化还是缺乏方向；
- 哪些证据支持当前判断，哪些证据反对；
- 当前允许产品承担怎样的共同风险上限；
- 什么条件会让当前判断失效，什么时候复查。

宏观层不是预测点位、选择产品或生成交易动作的模块。

## 六个宏观模块

| 模块 | 需要回答的问题 | 典型证据方向 | 当前边界 |
|---|---|---|---|
| 增长 | 经济动能在改善、走弱还是分化？ | 生产、需求、就业和景气信息 | 具体指标及组合方式待验证 |
| 通胀与价格 | 价格压力来自哪里，方向和持续性如何？ | 居民价格、工业价格、工资、商品和服务价格 | 不用单一价格指标直接改变风险边界 |
| 流动性与信用 | 资金和信用条件在放松、收紧还是传导不畅？ | 货币、信用、融资条件和市场流动性 | 数据口径、来源与时点待验证 |
| 政策 | 政策正在托底、保持中性还是收紧约束？ | 货币、财政、产业、地产和资本市场政策 | 政策表态不能代替实际传导证据 |
| 全球外部环境 | 外部增长、利率、汇率和风险偏好如何影响共同边界？ | 全球增长、主要利率、汇率和跨市场压力 | 只作为共同环境输入，不选择境内外产品 |
| 事件风险 | 是否存在可能改变风险上限的突发事件？ | 地缘、金融稳定、流动性和制度事件 | 一条新闻不能直接改变长期判断或产生交易 |

“典型证据方向”不是已经确定的数据清单。具体字段、来源、发布时间和真实可得时间将在后续数据契约中另行定义。

## 统一状态卡

每个模块都使用同一组字段：

| 字段 | 记录要求 |
|---|---|
| 当前状态 | 用清楚的自然语言描述，不只给分数；无法判断时写“未知” |
| 变化方向 | 改善、恶化、稳定、分化或未知；具体词表待评审 |
| 数据截止时间 | 说明当前判断使用的信息截止到何时 |
| 主要证据 | 只记录可核验、当时可得且与结论直接相关的事实 |
| 反对证据 | 主动记录不支持当前判断的事实和替代解释 |
| 未知项 | 明确缺失、滞后、口径冲突或尚未核验的内容 |
| 置信度 | 表达证据完整度和判断稳定性；具体尺度待验证 |
| 失效条件 | 预先写出什么变化会让当前判断不再成立 |
| 下次复查日期 | 指定下一次重新检查的日期或事件条件 |

状态卡不要求每次得出强结论。“未知”“证据冲突”和“保持原判断”都是正式结果。

## 共同风险边界

宏观层只输出下列四种共同风险边界：

| 边界 | 含义 | 不代表什么 |
|---|---|---|
| 开放 | 共同环境没有要求产品额外收缩风险，产品可在自身规则内使用风险预算 | 不代表必须增加风险或买入某类资产 |
| 中性 | 共同环境证据均衡或方向不清，产品按既定约束保持审慎 | 不代表所有资产权重相同 |
| 收敛 | 不确定性或不利证据上升，产品不得继续扩大部分风险暴露 | 不等于执行暂停，也不直接给出减仓比例 |
| 防守 | 共同环境要求产品显著降低可承担风险的上限 | 不等于清仓，不指定具体资产动作 |

具体边界如何由六个模块形成、何时切换以及怎样映射到产品允许范围，均为待验证事项。本轮不建立评分公式、模块权重或阈值。

## 置信度不是第二套交易信号

置信度只描述证据质量和判断稳定性，用来提醒下游怎样理解宏观输出。它不能：

- 自动放大或缩小仓位；
- 替代共同风险边界；
- 掩盖反对证据和未知项；
- 在没有数据契约时制造精确分数。

置信度的具体表达方式保持待验证。

## 宏观层与执行层的边界

宏观风险边界和执行状态必须分开：

```text
宏观层：开放 / 中性 / 收敛 / 防守
执行层：正常 / 谨慎 / 暂停
```

宏观层可以要求产品收缩共同风险上限，但“暂停调整”“冻结执行”和“恢复执行”只能由执行与风险层依据预先定义的风险闸门决定。

## 宏观层明确禁止

- 选择代表指数或具体 ETF；
- 生成中波产品的最终权重；
- 产生买入、卖出、加仓、减仓或清仓动作；
- 根据一个指标直接改变产品约束；
- 根据一条新闻直接改变长期判断；
- 在来源、口径和时点未核验时输出确定结论；
- 用旧文章中的固定评分、阈值或资产结论补齐当前规则。

## 向下游提供什么

宏观层向资产角色层和产品风险预算层提供：

1. 六个模块的状态卡；
2. 一项共同风险边界；
3. 主要不确定性和反对证据；
4. 当前判断的失效条件；
5. 下次复查日期。

下游可以在这些约束内工作，但不能反向修改宏观判断。发现矛盾时，应进入[系统运转与优化闭环](/system-loop/)的问题记录。
