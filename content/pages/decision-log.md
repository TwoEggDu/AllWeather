系统决策记录保存的是项目边界和架构决定，不是投资交易日志。后续每次改变范围、层级职责、资产桶或验证门槛，都应追加一条记录，而不是直接覆盖旧决定。

## 2026-08-05｜D-001：公开名称确定为“蜗牛全天候”

- **问题**：公开名称应使用 PIRS Lite、AllWeather Lite、AllWeather，还是“蜗牛全天候”？
- **决定**：公开名称统一为“蜗牛全天候”；仓库名和 GitHub Pages 地址继续保留 `AllWeather`；PIRS 只作为内部方法来源。
- **原因**：“蜗牛”保留项目的个人身份，“全天候”直接说明资产配置方向；第一阶段的克制边界不需要变成永久品牌后缀。
- **排除**：不在公开站点同时维护多套品牌名称。
- **重新评估**：只有项目未来需要与其他仓库统一品牌时再讨论命名。

## 2026-08-05｜D-002：旧文章隐藏但不删除

- **问题**：原有大量宏观文章会分散新读者对主线的理解。
- **决定**：旧文章、词汇表和栏目退出生产构建，源文件和 Git 历史继续保留。
- **原因**：先让蜗牛全天候的新定位成为唯一公开入口，同时保留未来逐篇吸收的可能。
- **排除**：不批量删除旧文章，也不把旧文章中的具体参数自动视为现行规则。
- **重新评估**：每篇内容完成边界、数据和引用复核后，可单独恢复公开。

## 2026-08-05｜D-003：第一阶段只保留六个资产桶

- **决定**：现金、债券、红利、宽基、成长主题、黄金。
- **原因**：六个桶足以覆盖流动性、防守、基础权益、进攻与对冲角色，同时保持个人可理解性。
- **排除**：商品、REITs、外汇、加密资产和复杂衍生品暂不进入现行范围。
- **重新评估**：现有六桶完成一次可复查模拟闭环之后。

## 2026-08-05｜D-004：参数在验证前保持未定

- **决定**：当前不公布目标权重、评分公式、固定阈值和具体 ETF。
- **原因**：没有数据、口径、基准与历史回放的参数只会制造虚假精确。
- **排除**：不直接沿用旧文章中的示例比例。
- **重新评估**：M1 数据契约完成并保留第一轮历史验证记录之后。

## 2026-08-05｜D-005：不接实盘与自动交易

- **决定**：第一阶段只做研究、模拟与复盘；人是唯一决策者。
- **原因**：当前目标是验证决策流程，而不是提高执行速度。
- **排除**：券商接口、自动下单、真实持仓写入和自动调参。
- **重新评估**：当前路线图没有安排重新评估时间。
