## 这个网站怎么用

蜗牛量化是一个面向所有读者的开放中国市场投研知识库。网站不再用手工维护的文章总数和长清单作为主要导航，因为这类信息会很快过期。

更有效的方法是先判断自己正在解决什么问题，再选择入口。

## 如果你正在做一个研究主题

按以下七个问题检查：

1. 触发事件和已确认事实是什么？
2. 政策想改变什么，执行到了哪一步？
3. 国家、地方、央国企和社会资本如何参与？
4. 需求、成本、价格、产能、订单和利润如何变化？
5. 市场资金正在定价什么，证据是什么？
6. 全球环境对这条逻辑是顺风还是逆风？
7. 下一个什么事实会验证或推翻当前结论？

可以在[研究栏目](/topics/)中按六个领域进入，也可以在[全部文章](/posts/)中用研究领域和标签交叉筛选。

## 如果你正在追踪一项政策

不要在“政策利好”处停止，继续追踪：

`政策表态 -> 正式文件 -> 配套细则 -> 资金落实 -> 项目与采购 -> 订单 -> 收入、现金流与利润`

## 如果你正在研究一个行业

先检查产业利好是否能够转化为企业利润：

`需求 -> 订单 -> 产量 -> 库存 -> 价格 -> 收入 -> 成本与毛利率 -> 资本开支 -> 现金流`

## 如果你在追踪市场热点

至少同时看五组信号：价格强弱、上涨广度、成交占比、持仓代理指标和基本面验证。

价格和成交可以证明资金行为，但不一定能证明资金身份。无法确认时，不把软件推算的“主力净流入”写成某类机构的确定买入。

## 如果你想使用全球信息

首先回答：它是否会改变中国的收入、成本、估值、资金或风险溢价？

如果这五项都没有明显变化，这条全球新闻就不必进入核心中国投研体系。

## 阅读动态文章前的检查

- 数据截止日期是什么？
- 统计口径和原始来源是什么？
- 这是当前研究还是历史快照？
- 文章是在陈述事实，还是提出推断和假设？
- 下一个复核节点和失效条件是什么？

网站不要求读者同意每一篇文章，但希望每一个结论都能被理解、检验和修正。

## 反例 / 风险

- 栏目和标签映射仍处于迁移期，旧文章可能同时进入多个研究领域。
- 文章数量多不代表当前数据已经完成复核。
- 公开信息可能存在披露延迟、口径变化和数据修订。
