# 蜗牛量化开放投研内容架构与改造清单

> 本文档将《中国市场投研体系顶层设计》转化为站内内容改造方案。目标是先建立清晰的内容分层和修改顺序，再逐批修订文章，避免一次性重写全站。

---

## 一、本次盘点的基本结论

站内已有 180 篇文章，其中 179 篇标记为已发布。宏观、政策、五年规划、地缘、产业链、资产配置和复盘方法已有大量素材，因此当前的首要问题不是文章数量不足，而是以下四点：

1. **定位不够清晰**：站点介绍、阅读路径和部分文章仍以个人学习日志为主，尚未明确表达“面向所有研究者的开放中国市场投研知识库”定位。
2. **分类失效**：现有 179 篇已发布文章中，72 篇归为“宏观基础”，66 篇归为“交易表达”。两个大类过于宽泛，无法帮助研究者快速定位政策、国家资本、基本面和市场资金。
3. **知识点多，工作链不完整**：已有文章分别解释了美联储、人民币、中国财政、社融、五年规划和行业主题，但缺少“政策—国家资本—项目—企业利润—市场资金—全球反馈”的统一入口。
4. **动态结论与长期知识混合**：部分文章在标题或摘要中使用当前规模、市场份额、收益数字、“最新”、“当前估值”和“2026 现状”，但没有统一的数据截止、更新周期和过期状态管理。

因此，下一阶段应从“继续增加选题”转向“重建开放投研索引、补齐关键环节、逐批提高证据质量”。

## 二、开放使用的五层内容架构

### L0：当前状态与工作台

回答“今天和本周发生了什么”，服务日常观察、周会和复盘。

应包含：

- 中国宏观状态：增长、通胀、信用、流动性和政策阶段。
- 全球外部环境：美债利率、美元、全球需求、商品与地缘事件。
- 市场结构：宽基、风格、行业强弱、成交广度和拥挤度。
- 政策和国家资本的最新执行节点。
- 正在跟踪的热点、下一个验证数据和主要风险。

输出形式应是仪表盘、周报、热点卡和政策进度表，而不是长篇知识文。

### L1：专题研究与当前判断

回答“当前市场正在交易什么，这条逻辑走到哪一步”。

包括：

- 政策专题跟踪。
- 国家资本和地方产业基金地图。
- 行业景气、供需和利润落点。
- 热点生命周期与资金结构。
- 全球变量对中国资产的当期影响。

每篇文章必须有数据截止、当前阶段、事实、推断、竞争性解释、下一个验证节点和失效条件。

### L2：可复用的分析模型

回答“以后再遇到同类问题，应该怎么分析”。

包括：

- 政策从表态到利润的传导模型。
- 中央和地方财政分析模型。
- 产业基金、政策性金融和央国企资本开支的跟踪模型。
- 行业供需、价格、库存、订单和利润的研究模型。
- 市场宽度、风格、资金代理指标和拥挤度的观察模型。
- 全球冲击到中国的五条传导模型。

这一层尽量保持长期稳定，少写容易过期的当前数字。

### L3：底层知识和历史案例

回答“为理解 L1 和 L2，研究者需要补哪些背景”。

包括：

- 宏观基础概念和市场机制。
- 中国房地产、地方财政、社融、人民币和国企等制度背景。
- 五年规划和历史政策周期。
- 中国和全球宏观冲击的历史复盘。
- 产业链和利润池研究方法。
- 决策日志、研究偏误和风险管理。

已有文章的大部分适合进入这一层，应保留但不必放在首页的最主要位置。

### L4：外围资料和归档

与当前核心投研主线关系较弱，但可能仍有保留价值的内容。

主要包括：

- 海外账户开设与券商比较。
- 个人税务、房贷、保险和家庭财务。
- 纯工具选择和面向个人投资者的实操指南。
- 与中国市场传导链联系较弱的海外市场介绍。

建议先从核心导航中移出，保留原文并标记为归档或外围阅读，暂不删除。

## 四、需要补充的核心内容

### P0：投研系统的枢纽文章

1. **中国市场定价总框架**
   政策、国家资本、基本面、市场资金和全球反馈如何共同定价中国资产。

2. **全球宏观影响 A 股的五条传导链**
   美债与美元、全球需求、商品、全球产业资本开支、地缘与贸易政策。

3. **政策从表态到利润的执行地图**
   区分文件、细则、预算、资金、项目、招标、订单和现金流。

4. **国家资本和地方产业基金总地图**
   区分财政、政策性金融、央企资本开支、国家级基金、地方引导基金和国资运营平台。

5. **市场资金分析的可观察指标体系**
   明确哪些数据可以证明成交和持仓变化，哪些“资金流”只是算法估算。

### P1：国家资本与地方资金专题

1. 中央财政、特别国债和重大工程的资金链。
2. 政策性银行和结构性金融工具如何进入产业。
3. 央企资本开支和专业化整合跟踪。
4. 地方产业引导基金的认缴、实缴、返投和招商机制。
5. 如何避免母基金、子基金和撬动资本的重复计算。
6. 政府采购、示范项目和应用场景对新产业的早期需求作用。
7. 国家资本在半导体、AI 算力、电网、商业航天、高端装备、生物医药等方向的标准化案例。

### P1：基本面与市场资金的连接

1. 中国行业的月度供需—库存—价格—利润跟踪模板。
2. 政策利好与企业利润改善之间的证据门槛。
3. 行业 ETF 份额、成交占比、广度、相对强弱和拥挤度的统一口径。
4. 指数调整、量化资金、融资资金、ETF 资金和产业资本对价格的不同影响。
5. 政策—基本面—资金共振和背离的情景矩阵。

### P2：中国与全球反馈

1. 中国新增产能如何改变全球供给与价格。
2. 国产替代如何从减少进口转为出口竞争。
3. 中国投资如何改变全球金属、能源和关键材料需求。
4. 海外关税、反补贴、本土补贴和出口管制的反馈链。
5. 中国企业海外建厂、资源布局和技术标准输出的长期影响。

## 五、现有文章的修改类型

### 类型 1：改受众和用途

需优先修改：

- `content/_index.md`
- `content/pages/about.md`
- `content/pages/macro-index.md`
- `content/posts/blog-index-learning-paths.md`
- `data/topics.yaml`

修改方向：将“个人学习型博客”改为“蜗牛量化开放中国市场投研知识库”；保留对新读者友好的入门路径，同时新增宏观、政策、国家资本、基本面、市场资金和复盘的研究路径。

### 类型 2：改分类和元数据

现有 `category` 只有少量宽泛值，无法支持结构化检索。建议新增或重构以下维度：

- `research_layer`：`current` / `model` / `reference` / `archive`
- `research_domains`：可以同时选择 `policy` / `state-capital` / `fundamental` / `market-flow` / `global-china` / `review` 中的一个或多个领域
- `market_scope`：`a-share` / `hong-kong` / `rmb` / `rates` / `commodities` / `cross-market`
- `as_of`：动态文章的数据截止日期
- `review_cycle`：`weekly` / `monthly` / `quarterly` / `event-driven` / `static`
- `maintainer`：可选的文章维护人或主要贡献者
- `review_status`：`current` / `needs-review` / `historical-snapshot`

在模板、校验脚本和导航支持这些字段之前，不建议直接批量写入 179 篇文章。

### 类型 3：将当期文章改为有日期的快照

优先复核以下文章：

- `china-fyp-15-2026-2030-outlook.md`
- `how-to-track-china-national-team.md`
- `hong-kong-market-deep-dive.md`
- `ai-mega-trend-deep-dive.md`
- `climate-investing-carbon-markets.md`
- `stablecoins-cbdc-monetary-sovereignty.md`
- `gold-and-central-bank-reserves.md`
- `semiconductor-investing-advanced.md`
- `china-public-reits-guide.md`
- `crypto-as-alternative-allocation.md`

修改要求：

- 标注数据截止日期。
- 精确数字优先使用原始或权威来源。
- 分开已发生事实、当前推断和未来情景。
- 标明下一复核时间或事件触发条件。
- 过期后标记为历史快照，不覆盖当时判断，通过新版本或复盘记录更新。

### 类型 4：去掉面向个人投资者的推荐语气

站内有较多“具体标的”“推荐配置”“买卖信号”“时机判断”和“怎么买”类表述。开放投研内容应将这些部分改为：

- 产业链上市公司映射，而不是推荐标的。
- 价格、成交、份额、基本面和估值的可观察条件，而不是买卖信号。
- 不同情景下的传导方向，而不是单一配置建议。
- 风险暴露和失效条件，而不是简化的买入时点。

优先处理行业专题、市场专题和实操指南，不需一次改完所有表述。

### 类型 5：修复导航、统计和审计记录

- `blog-index-learning-paths.md` 仍称全站有 164 篇文章，已与实际数量不一致。
- `docs/content-audit.md` 仍记录审计 13 篇文章，不能代表当前 179 篇已发布内容的状态。
- `macro-index.md` 主要按美国宏观学习路径组织，缺少中国定价与开放研究流程入口。
- `data/topics.yaml` 的五个栏目不再能覆盖新的投研主线。

### 批次 4：建立持续更新工具

- 周度外部环境仪表盘。
- 政策执行进度表。
- 国家资本与地方产业基金数据表。
- 行业景气与利润验证表。

### 批次 5：处理历史快照和外围内容

- 为过期快照补充状态和日期。
- 将个人财务、海外账户和投资工具文章移出核心导航。

## 八、验收标准

完成第一轮改造后，任何研究者都应能在站内快速完成以下任务：

1. 在一个入口看到中国市场定价的完整主线。
2. 当一项政策发布时，能找到资金来源、执行主体、实物工作量和利润落点的跟踪方法。
3. 当一个板块走强时，能区分政策驱动、景气驱动、流动性驱动和防御轮动。
4. 当全球变量变化时，能快速映射到中国的收入、成本、估值和风险溢价。
5. 能看出一篇文章是长期机制、当期快照、未验证假设还是历史归档。
6. 每个当前判断都能找到下一验证数据、维护状态和失效条件。

达到这些标准后，站点才算从“文章集合”转变为“蜗牛量化开放投研知识库”。
