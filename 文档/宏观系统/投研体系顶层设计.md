# 中国市场投研体系顶层设计

> 本文档是站内后续选题、写作、跟踪和复盘的共同参考。它不直接给出买卖结论，而是规定我们研究什么、如何建立因果链、用什么事实验证，以及如何区分事实与判断。

## 适用对象和使用场景

本站是蜗牛量化建设的开放投研知识库。内容面向所有关注中国市场的研究者和读者，不限于固定组织内部成员。我们以公开、可追溯的信息为基础，通过结构化写作、数据验证和持续复盘，共同积累一套可阅读、可检验、可修正的中国市场投研体系。

### 四项基础建设

1. **开放研究使命**：基于公开信息，持续研究中国宏观政策、国家资本、产业基本面和市场资金，并允许任何读者检验、质疑和改进现有结论。
2. **研究边界**：以中国资产为终点；全球内容只在能够改变中国需求、成本、估值、资金或风险溢价时进入核心体系；不以荐股、喊单和短期涨跌预测为主要产出。
3. **研究便捷性**：通过统一导航、标签、模板、数据日期、相关专题、历史版本和复盘入口，让读者能够快速找到一个政策、资金通道、产业链环节或市场热点的完整证据链。
4. **内容纪律**：分开事实、推断和假设；为动态数字标注截止日期和来源；区分政策表态、资金落实和利润兑现；为当前判断保留验证条件、失效条件和修订记录。

核心使用场景包括：

- 快速补足某个政策、宏观变量或产业链的必要背景。
- 为日常市场观察、定期复盘和专题研究提供统一口径。
- 跟踪政策、国家资本、地方产业基金、行业基本面和市场资金之间的进展。
- 为量化信号设计、因子解释、情景标注和异常复盘提供可验证的机制假设。
- 保留研究者在当时可知的事实、推断、分歧和后续验证结果。

文章的价值优先由“能否支持研究、验证和复盘”衡量，而不是由话题覆盖数量或投资工具推荐的完整度衡量。入门友好性值得保留，但不能代替证据链和可验证性。

## 一、研究定位

我们只研究中国市场，以 A 股为主，必要时将港股、中国债券、人民币、境内商品和中概股作为观察中国资产定价的辅助市场。

我们研究全球，不是为了覆盖全球投资机会，而是回答：

> 全球增长、利率、美元、商品、贸易政策和地缘变化，会如何改变中国的需求、成本、产业能力、资金条件和风险溢价。

投研系统需要持续回答五个问题：

1. 当下市场正在交易什么？
2. 是什么政策、事件或数据改变了预期？
3. 政策和资金最终会流向哪里？
4. 收入、成本、订单、产能和利润是否会真正改变？
5. 什么新事实能够验证或推翻当前逻辑？

## 二、投研体系的四条主线

### 1. 宏观与产业政策

回答“方向、约束和激励发生了什么变化”。

研究范围包括：

- 货币政策：政策利率、存款准备金率、公开市场操作、结构性工具和信贷导向。
- 财政政策：赤字、一般公共预算、政府性基金预算、专项债、特别国债和支出进度。
- 信用政策：社融、信贷结构、地产融资、地方化债和政策性金融。
- 产业政策：五年规划、专项规划、重大工程、行业准入、补贴、税收、采购和监管规则。
- 资本市场政策：发行、再融资、减持、回购、分红、并购重组和长期资金入市制度。

政策分析必须区分六个阶段：

`政策表态 -> 正式文件 -> 配套细则 -> 资金落实 -> 实物工作量 -> 企业订单与利润`

不得将政策表态直接等同于企业基本面改善。

### 2. 国家资本与地方产业资金

回答“国家真正将钱投向哪里，谁负责执行，社会资本是否跟进”。

需要分开研究：

- 中央和地方财政资金。
- 政策性银行和结构性融资工具。
- 中央企业和地方国企的资本开支。
- 国家级产业基金。
- 地方政府引导基金、母基金和子基金。
- 国有资本投资、运营和并购整合平台。
- 政府采购、示范项目和应用场景开放。
- 稳定资本市场的国有和长期资金。

资金跟踪必须区分：

`规划金额 -> 认缴规模 -> 实缴规模 -> 投资决策 -> 项目落地 -> 设备采购 -> 收入和现金流`

不得将宣布成立的基金规模当作已投资金额，也不得将母基金、子基金和拟撬动社会资本重复加总。

### 3. 行业与企业基本面

回答“政策和资金是否转化为真实需求，利润最终落在哪个环节”。

统一使用以下链条：

`需求 -> 订单 -> 产量 -> 库存 -> 产品价格 -> 营业收入 -> 成本与毛利率 -> 资本开支 -> 现金流与利润`

行业研究至少需要说清：

- 需求的真正来源和持续时间。
- 价格的决定者与企业的议价能力。
- 库存、产能和产能利用率的位置。
- 政策资金落在设备、材料、工程、运营还是应用环节。
- 收入增长来自量、价、并购还是会计口径。
- 订单和收入能否转化为自由现金流。
- 新增资本开支是强化竞争力，还是带来未来供给过剩。

### 4. 市场资金与交易结构

回答“为什么是现在涨跌，哪些资产正在获得相对优势，行情处于什么阶段”。

重点观察：

- 全市场成交额、换手率和上涨广度。
- 大盘与小盘、价值与成长、高股息与高弹性的相对表现。
- 行业成交占比、相对强弱、上涨家数和龙头扩散。
- ETF 份额、融资余额、股指期货基差和持仓等可观察代理指标。
- 上市公司回购、重要股东增减持和产业资本动向。
- 债券收益率、资金利率、人民币和商品的交叉验证。

“主力净流入”等根据成交方向推算的数据不能单独用来确认资金身份。无法确认时，只描述可观察的价格、成交、份额和持仓变化。

## 三、统一因果链

所有宏观、政策、产业和热点研究，尽量放入同一条因果链：

`国内或外部变化 -> 政策反应 -> 国家与社会资本投向 -> 需求、成本或产能变化 -> 企业利润变化 -> 市场资金定价 -> 中国产业能力变化 -> 全球供需与政策反馈`

每一个箭头都要提供机制解释和可观察指标。如果中间环节尚无证据，要明确标注为待验证推断，不用叙事代替证据。

### 全球变量进入中国市场的五条主要路径

1. 美债利率与美元 -> 人民币、跨境资金、中国政策空间与估值。
2. 全球需求 -> 中国出口、订单、航运和出海企业利润。
3. 全球商品价格 -> 中国输入成本、PPI 和上中下游利润分配。
4. 全球产业资本开支 -> 中国设备、零部件、材料和工程供应链。
5. 地缘、关税和出口管制 -> 国产替代、企业出海、产能迁移和风险溢价。

全球内容最后必须落到中国的收入、成本、估值或风险溢价。四者都没有明显变化时，不必进入核心投研系统。

### 中国国家资本对全球的反向影响

中国的政策和资本投入形成产业能力后，需要继续跟踪：

- 新增产能是否改变全球供给和产品价格。
- 中国投资是否改变能源、金属和关键材料的全球需求。
- 国产化是否从进口替代转为出口竞争。
- 海外是否以关税、反补贴、本土补贴、出口管制和友岸外包回应。
- 中国企业是否通过海外建厂、资源投资、长协和技术标准扩大全球影响。

时间上分为三层：

- 1–2 年：政策、基金、招标、订单和主题定价。
- 3–5 年：产能、产品价格、行业集中度和全球市场份额。
- 5–10 年：技术标准、关键供应链节点和全球产业秩序。

## 四、热点与资金流研究

### 热点的五项确认信号

1. 价格：是否持续跑赢宽基指数。
2. 广度：是少数龙头上涨，还是板块内部扩散。
3. 成交：成交额和换手率是否持续提升。
4. 资金：ETF 份额、融资和其他可观察持仓是否确认。
5. 基本面：价格、库存、订单、收入或利润预期是否发生变化。

### 热点的性质

- 事件型：政策、新闻或突发事件驱动。
- 流动性型：资金集中，基本面尚未明显变化。
- 景气型：需求、价格、订单或利润开始改善。
- 长期产业趋势型：政策、资本开支和产业渗透率持续提升。
- 防御型：风险上升后，资金转向低波动或避险方向。

### 热点的生命周期

`信号出现 -> 龙头启动 -> 行业扩散 -> 叙事强化 -> 资金拥挤 -> 基本面验证或证伪 -> 延续或退潮`

每次跟踪都要标记当前阶段，避免把“长期逻辑正确”与“当前价格值得追逐”混为一件事。

## 五、证据和表述纪律

即使内容主要供自己浏览，也必须保留最小可追溯性。

### 三层信息必须分开

- **事实**：可被原始数据、文件、公告或价格记录验证。
- **推断**：由多个事实推出的最可能解释，但仍可能存在竞争性解释。
- **假设**：对未来的可检验判断，必须写出验证条件和失效条件。

### 动态数据的最小记录要求

- 数据截至日期。
- 指标定义和统计口径。
- 原始来源或可重新找到原始数据的入口。
- 与上一期或合理基准的比较。
- 数据修订、口径变化和季节性影响。

常用证据按优先级包括：正式政策文件、政府预算和决算、国资与政府部门公开信息、招投标和采购文件、基金工商与管理人信息、上市公司公告和财报、行业协会与可验证的市场数据。

## 六、站内内容架构

后续文章和研究记录围绕六个内容入口组织：

1. **宏观与政策**：政策方向、工具、执行阶段和传导机制。
2. **国家资本与产业方向**：中央、地方、央国企和产业基金的实际投向。
3. **行业与企业基本面**：从需求、订单、价格到利润和现金流。
4. **资金与市场结构**：总量流动性、风格、行业和可观察资金行为。
5. **全球变量与中国资产**：只保留能够进入中国定价链条的全球内容。
6. **热点跟踪与复盘**：记录热点阶段、发生原因、资金证据、验证数据和证伪过程。

## 七、文章类型与统一结构

### 文章类型

- **机制文**：解释一个长期有效的传导机制。
- **政策跟踪文**：记录政策从表态到执行和基本面的进展。
- **国家资本地图**：跟踪某产业的资金来源、执行主体、项目和利润落点。
- **行业基本面文**：检查产业供需、价格、库存、订单和利润。
- **热点跟踪卡**：高频更新热点性质、阶段和可验证信号。
- **案例复盘文**：回溯当时可知事实、市场定价与后续证伪。

### 通用写作结构

1. 这篇文章要回答什么问题。
2. 截至当前已确认的事实与数据。
3. 政策、资金、基本面和市场之间的机制链。
4. 国家资本和社会资本分别处于什么阶段。
5. 利润最可能落在产业链哪个环节。
6. 市场当前在交易什么，资金证据是什么。
7. 全球变量如何影响中国，中国又可能如何反向影响全球。
8. 竞争性解释、反例和风险。
9. 下一次验证节点与失效条件。

## 九、选题优先级

优先建设能够连接已有内容的枢纽文章，而不是继续平行增加国家和主题介绍。

### 第一优先级：总框架

1. 《中国市场到底在交易什么：政策、国家资本、基本面与市场资金》
2. 《全球宏观如何影响 A 股：五条核心传导链》
3. 《国家资本地图：从中央财政到地方产业基金》
4. 《全球变量 × 中国行业敏感度矩阵》

### 第二优先级：可复用工具

1. 政策从发布到利润的跟踪表。
2. 地方产业基金核查卡。
3. 国家资本产业投向数据表。
4. 行业热度与拥挤度跟踪卡。
5. 周度中国市场外部环境仪表盘。

### 第三优先级：标准案例

选择能够检验整条因果链的历史或当前专题，统一复盘“政策、资金、基本面、市场定价和全球反馈”，不只复述事件时间线。

## 十、体系的最终检验

一篇文章或一张研究卡只有在以下问题上提供了新信息，才值得进入核心投研系统：

- 政策方向或执行阶段是否变了？
- 国家、地方或社会资本的实际投向是否变了？
- 需求、价格、订单、产能、利润或现金流是否变了？
- 市场资金的风格、广度、强度或拥挤度是否变了？
- 全球环境是在加强还是削弱这条中国产业逻辑？
- 已有判断的验证条件或失效条件是否被触发？

这套体系的目标不是为每次涨跌编造一个完美故事，而是稳定回答：

> 现在发生了什么，钱正在往哪里去，为什么往那里去，以及下一个什么事实会证明我们是对的或错的。
